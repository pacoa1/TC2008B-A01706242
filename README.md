# Chivas: El camino a la 13

Juego de penales hecho en Unity 6.6 para la materia TC2008B. En este juego, eres el cobrador de Chivas en una liguilla que se decide en tandas de penales: elimina a Gallos, Cruz Azul y América para ganar el tan ansiado título 13.

Video de la partida completa: https://youtu.be/yRbMtTuUtiY

## Cómo abrirlo
1. En Unity Hub, agrega la carpeta `Chivas_la13`.
2. Abre la escena `Assets/Scenes/Menu` y presiona Play.

## Controles
| Tecla | Acción |
| --- | --- |
| Espacio (1.er toque) | Fija la dirección del tiro |
| Espacio (2.º toque) | Fija la altura del tiro |
| Espacio (3.er toque) | Fija la fuerza y patea |
| Espacio (al terminar la tanda) | Pasa a la siguiente ronda o reintenta la actual |
| Esc | Pausa: continuar, reiniciar la ronda o volver al menú |
| Clic | Botones de los menús |
